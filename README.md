# Personal Task Manager

## Description

A desktop task manager application where users can add tasks, mark them as completed, delete tasks, view statistics, and switch between dark and light themes.

## Technologies

- Python
- CustomTkinter
- Pillow

## How to run

1. Install the required libraries:

```bash
pip install customtkinter pillow
```
2. Run the project:
```
python main.py
```
## Features
- Add new tasks
- Prevent empty tasks
- Mark tasks as completed
- Delete tasks
- View statistics
- Switch between dark and light mode
